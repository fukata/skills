# counterparty-check

業務委託案件の発注元や取引候補になる相手（会社・個人）について、関わる前に知っておくべき懸念がないかを公開情報から調べるスキルです。相手ごとに「懸念なし・要確認・避けるのが無難・情報不足」のどれかを、出典の URL と一緒に返します。

会社について調べること:

- モラル面: 訴訟・行政処分・炎上、事業そのものの倫理面、代表者の経歴
- 財務面: 決算の数字、資金調達、債務超過や未払いの報告
- 国税庁の法人番号公表サイトで、登記の有無・法人番号・所在地・変更履歴も確かめます

個人について調べること:

- 対象は、取引の相手になる個人事業主・フリーランスと、取引相手の会社の代表者・役員だけです
- 本人の特定、名乗っている経歴・資格の裏付け、取引に関わる訴訟・処分・未払いなどの報告、インボイスの登録（登録番号がある場合）
- 私生活・家族・信条・私用の SNS・破産者の情報は調べません。同姓同名の別人と区別できない情報は報告に載せません

## 導入

```bash
npx skills add fukata/skills -g -a claude-code -s counterparty-check
```

hook は使いません。外すとき:

```bash
npx skills remove -g counterparty-check
```

## 依存

- Web検索とページの取得ができるエージェント（Claude Code では WebSearch と WebFetch）
- [agent-browser](https://github.com/vercel-labs/agent-browser)（法人番号公表サイトの検索に使います。無ければ、ほかのブラウザ操作の道具で代わりにするか、検索できなかったことを報告に書きます）

## 使い方

会社名か氏名を渡して呼び出します。所在地や事業内容を添えると、似た名前の別会社と取り違えにくくなります。個人は氏名だけでは同姓同名の別人と区別できないので、屋号・職種・地域・本人のサイトなどを添えてください。

```text
/counterparty-check 株式会社A
/counterparty-check 株式会社A 株式会社B 株式会社C
/counterparty-check 株式会社A（恵比寿、チケット販売）
/counterparty-check 山田太郎（屋号: ヤマダ設計、Webデザイナー、福岡、https://example.com/）
```

- 結果は会話に報告します。ファイルには保存しません。
- 会社について調べるのは、会社・運営サービス・代表者と役員の公的な活動・報道・開示資料・口コミサイトまでです。一般社員個人の SNS は調べません。
- 取引の相手ではない個人（知人、交際相手、近隣の人など）は調べません。
- 申出・提訴・告訴は一方の主張として扱い、どの段階かを報告に書きます。

手順と判断の基準は [SKILL.md](SKILL.md) にあります。
